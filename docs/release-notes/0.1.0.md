# 易搜 YiSou 0.1.0

首个 Rust 正式版，面向 Windows 11 x64。Lite 和 Full 各以一个可直接运行的 EXE 发布。

## 主要功能

- 双击左 Alt 打开搜索框，支持输入、划词和剪贴板搜索。可保留关键词切换引擎，或在搜索框内查找历史。
- 支持编辑、启用和排序内置搜索引擎，添加自定义引擎，指定浏览器，以及筛选搜索历史和撤销单条删除。
- 搜索框支持亚克力、云母和纯色背景，历史浮层可以跟随搜索框的整套背景。可从托盘打开 Windows 11 Fluent 风格的设置界面。
- Lite 和 Full 均支持截图搜图，可将同一选区同时交给 Yandex Images 和 Google Lens 搜索来源。
- Full 额外提供本地截图 OCR，可从识别结果中选择文字并搜索。OCR 默认关闭，模型可从设置页的 ModelScope 入口下载。

## 下载与运行

- `YiSou-0.1.0-windows-x64-lite.exe` 适合文本搜索和截图搜图。
- `YiSou-0.1.0-windows-x64-full.exe` 额外支持截图 OCR。
- `SHA256SUMS.txt` 提供两个 EXE 的 SHA-256 校验值。

缺少运行库时，请安装 Microsoft Visual C++ x64 Redistributable。截图搜图会将确认的图片区域发送给所选搜索服务。运行要求、运行库下载地址和 OCR 配置步骤见使用说明。[使用说明](https://github.com/jinghu-moon/YiSou/blob/main/docs/distribution.md)
