# 易搜 UI 设计语言

本文以 C++ 基线 `6e3054a` 的实现为依据。数值默认以 DIP 表示，典型窗口和控件的物理尺寸随目标显示器 DPI 变化。实现时按像素落点检查图标、细边和文字，验收时使用实际窗口截图。

## 外观与层级

易搜使用 Windows 11 风格的浅色桌面工具界面。浮动搜索框以单行文本输入为中心，右侧固定当前引擎。引擎网格用于短时选择，设置窗口通过左栏组织长期偏好。品牌图标保留原有色彩，界面蓝色用于焦点、当前项和主要操作。窗口、卡片、控件的轮廓以细边和浅底区分。

| 用途 | C++ 规格 |
| --- | --- |
| 侧栏、设置背景、引擎网格底 | `#F1F3F7` |
| 卡片、菜单面板、当前磁贴 | `#FAFBFD` |
| 细边框 | `#DDE2EA` |
| 主要操作、焦点描边、当前项标记 | `#005FB8` |
| 选中、悬停 | `#E6EEF9`、`#EBF0F7` |
| 设置普通按钮和按下态 | `#FFFFFF`、`#DEE7F5` |
| 设置正文和辅助文字 | `#1A1E26`、`#545E6F` |
| 菜单正文和辅助文字 | `#202124`、`#5E6570` |
| 搜索底色、正文和辅助文字 | `#FCFDFF`、`#1A2029`、`#536273` |
| 通用圆角 | 卡片 8，控件 6，网格外轮廓 12 |

设置使用系统消息字体，正文 14、说明 12、标题 30 半粗。搜索默认优先 Microsoft YaHei UI，再尝试 Segoe UI。输入字号 16。引擎网格名称 13 半粗，别名 11 常规。语言可在简体中文、英文和跟随系统间切换。设置按钮宽度应能容纳两种语言。网格长名称用省略显示，同时保留完整名称供提示和键盘辅助识别。 [共用视觉数值](../src/ui/visual_style.h) · [设置排版](../src/ui/settings.cpp) · [菜单绘制](../src/ui/engine_flyout.cpp)

## 浮动搜索框

```text
╭────────────────────────────────────────────────────╮
│ 搜索文本或 #别名                         图标 名称 ▾ │
│ 链接打开提示或浏览器失败提示                          │
╰────────────────────────────────────────────────────╯
```

- 默认 `580×56`。需要显示提示时增高至 83。文本输入左距 20、宽 397、高 30，光标高 21。引擎按钮 `134×34`，右距 12，品牌图标 20，箭头 16。
- 使用圆角和细边框。DWM Acrylic 可用时在背景上叠加浅色，系统禁用效果或接口不可用时使用实色。链接提示使用辅助色，浏览器失败使用 `#9D3026`。两者出现时输入区维持原位置。
- 默认放在目标显示器工作区的水平中心、垂直约三分之一处。非交互区可拖动，位置按显示器记忆。显示器工作区和 DPI 变化后检查窗口位置、文字输入区、点击命中区和菜单锚点。
- 打开时焦点进入输入框。`Enter` 搜索，合法链接可用 `Ctrl+Enter` 打开，`Ctrl+,` 进入设置。空输入 `↑` 恢复上次查询。`Tab` 在正常状态移动到引擎按钮，别名提示打开时先遵循提示的操作。IME 组合期间保留输入法对候选和确认键的控制。需要验收空输入、选区预填、最近查询恢复、临时引擎、失败重试及焦点恢复。

## 引擎菜单与别名建议

| 区域 | 布局与内容 |
| --- | --- |
| 引擎网格 | 默认 6 列，最多 3 行可见。列数受显示器工作区限制，超出时可滚动。拖到屏幕边缘时菜单仍要完整位于工作区。 |
| 带字磁贴 | `86×90`，图标 28。右上角显示 `#alias`，图标下显示名称。 |
| 无字磁贴 | `64×64`，图标 36，保留提示和控件名称。两种模式磁贴间距 6，外边距 10。 |
| 当前和键盘焦点 | 当前项浅底和底部蓝色短线。键盘焦点有清晰描边。悬停、按下、当前项和焦点可以分别辨识。 |
| 添加入口 | 网格末尾的加号进入设置的搜索引擎页并打开编辑器。 |
| 别名建议 | 面板宽 352，列表行高 34，图标 24。行内显示完整引擎名和 `#alias`，选中项有勾形标记，面板显示确认提示。 |

菜单用方向键、Tab 和 Home/End 导航，用 Enter 或空格确认，Esc 关闭。别名建议由输入的 `#` 开头触发，支持方向键选中及 Tab 补全。搜索框仍持有输入焦点。点选引擎后返回输入框，当前查询使用所选引擎。菜单已有系统高对比配色分支，复测需要检查高对比下的图标、文字和焦点边框。 [飞出菜单实现](../src/ui/engine_flyout.cpp)

## 设置窗口

采用可调整大小的 Windows 原生顶层窗口，标题栏与系统按钮由 Windows 提供。首开客户区目标 `788×482`，初始位置居中并受工作区限制。最小窗口外框 `667×345`。左栏宽 194，导航行高 42，主内容横向留白 26，最大宽度 720。滚动作用于内容区，保持导航可达。标题之后按说明、字段和操作排列。常用操作通过鼠标及 Tab 顺序可达，禁用操作在不可用时明确呈现。

| 页面 | 布局和交互 |
| --- | --- |
| 常规 | 登录启动、手动启动时显示搜索框、关闭后驻留托盘。语言选择和重启状态放在同一页。 |
| 外观 | 字体来源与当前字体、系统字体和文件选择、恢复默认、字体预览，以及引擎菜单的名称显示选项。需覆盖加载失败与恢复。 |
| 搜索引擎 | 引擎列表每行 52，包含图标、姓名和附属信息。提供添加、编辑、删除、排序、默认、置顶及测试。编辑区包含名称、别名、模板、颜色和图标，预览边长 42。错误提示与输入保留在编辑区。 |
| 快捷键 | 主快捷键、划词快捷键、剪贴板快捷键。划词引擎与行为下拉框，以及双 Alt 排除应用字段。包含录制、取消、已绑定和冲突状态。 |
| 浏览器 | 显示当前选择。系统默认项、已注册浏览器列表或 EXE 路径输入。列表行高 46，图标、名称和路径区分主次。无效路径和启动失败有可识别反馈。 |
| 搜索历史 | 记录开关、关键词和来源筛选。列表行高 104，每页 24 项，带空状态和翻页。选中记录后支持再次搜索与删除。 |
| 配置文件 | 当前路径、选择配置位置、完整配置导入导出、仅引擎导入导出。文件选择、字体、颜色等原生对话框遵循 Windows 键盘和焦点行为。 |

Esc 优先取消快捷键录制、折叠浏览器选择区、关闭打开的引擎编辑区，再关闭设置窗口。托盘菜单使用系统菜单，提供打开搜索框、设置和退出。 [设置窗口实现](../src/ui/settings.cpp) · [托盘实现](../src/ui/search_window.cpp)

## 图标与视觉验收

- 原始 SVG 使用原生品牌色或界面定义的图标色。迁移基线为 resvg 16× 加缩小，按目标物理尺寸缓存结果。资源绘制保持宽高比与透明边缘。同一个图标在不同控件之间按其目标大小栅格化。
- 对比 100%、125%、150%、175%、200% 下的搜索按钮、引擎菜单两种模式、别名行和编辑预览。覆盖浅底和高对比、单色细线、彩色实心、透明半边、圆弧及不规则曲线。在真实窗口检查模糊、边缘灰边、图标被裁、对齐和点击区域。
- 截图使用两版相同工作区、DPI、语言、引擎顺序、配置和调色条件。采集搜索初始、正常输入、链接、失败、别名建议、带字和无字网格、滚动末尾、设置七页与错误状态。记录屏幕缩放和 Acrylic 是否启用。
- 实机验证跨屏、IME 候选、键盘导航、长名称、路径过长、空历史、列表满页和保存异常。图标测试窗口验证资源和算法，产品窗口验证显示结果和交互。

## Rust UI 的性能与动效

- 搜索框一旦可见即可输入。显示后的第一帧提供稳定的输入区和引擎位置。托盘空闲时按事件唤醒。窗口显示、菜单打开和滚动的数据准备有独立测量。
- 视觉保持清晰层级、对齐和可见焦点。打开菜单、进入设置、选择和关闭后都有确定的键盘焦点。窗口缩放与长文本时保持主要操作可达。
- 动效集中在浮窗显隐、菜单展开和必要的状态变化。初始目标为 100–150 ms 的淡入或短位移，用实机测量调整。动画期间可以立即输入、键盘确认或取消。遵循 Windows 动画关闭设置，关闭时直接显示目标状态。
- UI 方案在底层和消费层验收后供用户选择。每套方案展示同样的窗口、菜单、焦点路径和 DPI 测试，用代表性原型评估响应、占用和外观。
