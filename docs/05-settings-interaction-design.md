# 易搜设置界面交互与外观方案

请为 Windows 搜索工具「易搜」制作一个可交互的设置窗口 Demo。它应能完整演示如何更换默认搜索引擎、管理快捷位、录制快捷键、配置 OCR 和从历史发起搜索。使用现有产品功能和真实长度的文案，便于直接评审界面。

## 现状与改版重点

现有 Rust 版从托盘「设置」或搜索框 `Ctrl+,` 进入。窗口可调整大小，有系统标题栏、固定的图标侧栏、Fluent 浅色卡片和内容滚动区。当前七页为常规、外观、搜索引擎、快捷键、浏览器、搜索历史和配置文件。Full 版把 OCR 模型、下载和快捷键都放在「快捷键」底部。已有截图用于参考视觉基线，功能以当前源码为准。 [现有设置页实现](../src/native/preferences.rs) · [七页截图](../target/rust-memory/settings-rust-grid.png)

易搜特有的设置集中在三条操作链。第一条是「默认引擎、#别名、置顶快捷位」，三者各自独立，现有列表底部的六个按钮让操作对象和作用不容易扫读。第二条是「唤出、划词、剪贴板和 OCR」，每个入口接受的内容和触发后的动作不同，尤其容易混淆唤出与独立划词。第三条是「搜索历史」，这是能再次发起搜索的本机列表，筛选和逐条操作比卡片装饰更重要。外观页的字体示例目前用 26 DIP 展示，改版用实际搜索框的 20 DIP 预览。 [快捷键与置顶实现](../src/native/search_window.rs) · [持久化设置](../src/settings.rs)

当前页面切换会重建右侧控件，滚动会批量移动原生控件并重绘。现有实现已经做了批量定位和延迟重绘。Demo 要在同一窗口内验证连续滚动、快速切页和焦点恢复，正式实现也需要在本机复验。 [页面构建](../src/native/preferences.rs#L472) · [滚动布局](../src/native/preferences/fluent.rs#L312)

## 窗口和视觉

- 使用 Windows 11 Fluent 风格的桌面窗口。左栏固定，右侧内容按页滚动。保持系统标题栏的窗口形态。首开客户区建议约 900 × 580 DIP，侧栏 184 DIP，内容区最大宽度 740 DIP，页边距 24 DIP。至少适配 667 × 345 的紧凑预览尺寸。紧凑时把表单内并列的字段改为上下堆叠，列表中的次要信息可换行。
- 侧栏依次为「常规」「外观」「搜索引擎」「快捷键」「浏览器」「搜索历史」「OCR 搜索」「配置文件」。Full 显示 OCR，Lite 隐藏其入口和快捷键关联项。每个导航项保留 Tabler SVG 图标、文字、选中底和可见焦点。
- 延续现有浅色基线。背景 `#F1F3F7`，分组底 `#FAFBFD`，细边 `#DDE2EA`，正文 `#1A1E26`，说明 `#545E6F`，操作和焦点蓝 `#005FB8`，选中底 `#E6EEF9`。分组圆角 8 DIP，控件圆角 6 DIP。长表单使用分组标题和分隔线，列表使用整行布局。
- 中文优先 Microsoft YaHei UI，英文优先 Segoe UI。页面标题约 28 DIP，分组标题 16 DIP，正文 14 DIP，说明 12–13 DIP。功能图标 16–20 DIP，保留品牌图标原色。图标按钮提供可访问名称和提示。开关、展开、键盘焦点和错误均有可辨识的形态或文字。
- 切页直接显示稳定布局。仅局部菜单或对话框可用约 120 ms 的淡入，遵循系统动画设置。滚动、过滤和选择时保持行高、栏宽和工具位置稳定。一个页面最多一个常驻纵向滚动区。

## 各页布局与组件

### 常规

「启动与后台」使用三行双态开关。分别为「登录 Windows 时启动」「手动启动时显示搜索框」「关闭搜索框后驻留托盘」。第一项说明登录后驻留托盘，第三项在关闭状态提示 Esc 会退出易搜。「界面语言」单独分组，提供「跟随系统 / 简体中文 / English」下拉框和「应用」。仅变更后启用按钮，应用成功后当前窗口更新语言。开关保存失败时恢复原状态并在该行显示原因。

### 外观

将「搜索框字体」合并为一个设置组。显示当前来源和字体名，系统字体和本地字体文件是两种明确操作，旁边有「恢复默认」。本地字体成功加载后更新预览，加载失败时保留上一次可用字体。支持的文件后缀以当前实现为准，包含 `.ttf`、`.otf`、`.ttc`、`.otc`。

下方放一个接近真实搜索框的预览，文本和右侧引擎图标均为 20 DIP。样例「复杂中文 鬱鑿齒 · Search 123」。再用「显示名称 / 仅显示图标」分段控件配置引擎菜单，在旁边展示三枚磁贴随模式变化。菜单设置作用于菜单磁贴，预览搜索框右端保持当前产品的单图标入口。

### 搜索引擎

页首工具栏放引擎筛选框和「添加引擎」。筛选匹配名称和别名。列表上方放「置顶快捷位」紧凑条，标出已有的 `Alt+1` 至 `Alt+5`，作用范围是搜索框。默认项在列表内用「默认」文字标明。置顶状态用图钉标记，置顶超过五项时仍保留置顶状态，快捷键只展示前五项。说明文字和焦点提示应能区分 `#别名`、默认和置顶。

列表每行约 48–52 DIP，显示品牌图标、名称、`#别名`、必要的状态和行尾「更多」菜单。菜单提供设为默认和置顶或取消置顶。自定义引擎还可编辑、删除、上移和下移。移动只在自定义引擎之间生效，边界动作禁用。默认引擎已经是当前项时禁用「设为默认」。置顶与排序操作后保留行焦点。删除前确认，若引擎被用作默认或划词入口，确认文案提示对应设置受影响。

添加和编辑进入同一内容区的表单。名称必填，别名可选，模板需要 `http(s)` 和位于路径或查询等部分的 `%s`。字段旁提示缺少占位符、别名重复等错误。图标区包含预览、色样和本地 SVG 或位图选择。底部保留「测试搜索」「取消」「保存」。“测试搜索”在 Demo 展示替换关键词后的 URL。返回列表后恢复筛选和原位置，有未保存修改时询问是否放弃。

### 快捷键

使用等宽的分组设置行，左侧显示动作名称和必要区别，右侧显示按键样式、录制及清除或恢复。唤出易搜默认「双击左 Alt」，有选区时直接搜索，其余时候打开搜索框。划词单独设置搜索引擎和「直接搜索 / 打开搜索框」。剪贴板搜索使用默认引擎。双击 Alt 排除应用用可移除的 `.exe` 标签输入，回车添加，支持粘贴逗号分隔的应用名，应用后保存列表。Full 在此提供「OCR 快捷键」跳转至 OCR 页相应控件，录制入口集中管理。

录制在当前行展开，显示「按下快捷键」、捕获结果、「保存」和「取消」。Esc 取消录制并恢复焦点。冲突时在行内提示，保留此前生效的绑定及当前录制值。录制区域的宽度在未设置、录制中、已录制和冲突时保持稳定。

### 浏览器

使用单选列表，首项「跟随 Windows 默认浏览器」，其余显示已安装浏览器的图标、名称和路径。「选择其他浏览器…」展开一行路径输入和「浏览…」，接受有效的本地 `.exe`。路径可选中，长路径在窄窗口中折行或省略，焦点和指针都能查看完整值。更换后统一用「应用」提交，失败时保留原选择与用户输入。

### 搜索历史

页首放「记录搜索历史」开关，初始关闭。关闭时停止写入，已有记录仍可查询。其下是独立有标签的「搜索内容」和「来源应用」筛选框，键入后对列表做短防抖更新。结果按最近时间排列，每页 24 项。

行首以查询文本为主，以下一行显示引擎、来源应用和时间。操作区提供「再次搜索」与可通过键盘访问的删除动作，按 Enter 可再次搜索当前行。删除后焦点留在相邻行。分别提供「暂无搜索记录」和「没有符合筛选条件的记录」，后者带「清除筛选」。准备长查询、长应用名和两页以上的本地样例。

### OCR 搜索

仅 Full 显示。做成独立设置页，顺序为「启用 OCR 搜索」「本地模型」「快捷键」。本地模型区放文件夹路径、浏览和应用，提供「待配置」「正在检查」「模型可用」「文件缺失或校验失败」状态。启用前检查模型，失败时保留输入并指明具体文件。状态与路径在检查时保持位置稳定。

下载区域明确指向 ModelScope 的 PP-OCRv6 tiny，三个链接分别为检测模型、识别模型和字典。说明这三份文件应放在同一个目录。模型由用户提供，Demo 用模拟目录和模拟校验状态呈现整个流程。快捷键复用录制组件，默认 `Alt+Shift+O`，可清除。 [下载地址与模型定义](../src/ocr.rs) · [现有 OCR 设置](../src/native/preferences/ocr.rs)

### 配置文件

分成「当前配置」「完整配置」「搜索引擎包」三组。当前配置展示可选择的路径和「更换位置…」，更换后标明生效于下次启动。完整配置的导入会替换当前配置，确认时显示文件和作用范围。引擎包导入合并自定义引擎和置顶顺序，导出只包含对应数据。导入失败时显示错误并保留当前状态。两种导入和导出均保留独立按钮。

## 交互规则与验收

- 即时操作用于单项开关、显示模式和行内置顶等；语言、快捷键录制、路径、引擎表单和导入按各页的提交边界处理。普通成功在操作位置短暂反馈，错误就地显示。确认对话框用于覆盖配置、删除引擎和丢弃未保存修改。
- Tab 顺序从侧栏进入标题区和首个操作，再按视觉顺序前进。导航、下拉、分段和单选支持方向键。Esc 优先关闭弹层、取消录制或退出编辑，焦点返回触发控件。切页返回时恢复各列表的筛选和滚动位置。带脏数据的表单按明确的保存或放弃结果离开。
- 快速滚动快捷键页和历史列表，连续切换「搜索引擎 → 快捷键 → OCR 搜索」，然后拖动窗口尺寸。检查白闪、双重滚动、内容跳动、焦点丢失及操作被遮挡。正式 Windows 实现再用真实滚轮、不同 DPI 和屏幕录制验证重绘。
- 走通三条链路。添加自定义引擎并模拟测试 URL，设为默认后独立置顶；录制划词键并演示冲突、取消和保存；从 Full 未配置模型开始，分别演示文件缺失、检查通过、启用和取消录制。再切 Lite 验证导航和快捷键入口对应版本。
- 验收 900 × 580 与 667 × 345 两种布局、Windows 100% 和 150% 缩放、键盘操作、长中英文与长路径。至少交付引擎列表、引擎表单错误、快捷键冲突、OCR 模型未配置与可用、历史无匹配的截图。

## Demo 交付

交付一个可在本地打开的交互式 HTML Demo。首屏直接进入易搜设置窗口，默认展示 Full。提供 Full 和 Lite 两个原型入口或独立打开方式，版本选择放在演示入口。以模拟数据驱动设置、文件选择、模型检查和快捷键冲突，状态应能实际切换和恢复。使用项目内的 Tabler SVG，搜索引擎使用对应品牌 SVG。交付时附打开方式和各验收状态的复现步骤。
